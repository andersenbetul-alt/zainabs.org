# Güvenlik ve mahremiyet

Bu proje sağlık konularıyla ilişkili, herkese açık bir kaynak deposudur. Gerçek hasta bilgileri, tıbbi kayıtlar, kimlik numaraları, iletişim bilgileri, parolalar, API anahtarları veya bağış ödeme bilgileri asla GitHub Issue/PR/commit içine konulmamalıdır.

**Güvenlik açığı bildirimi:** GitHub deposunun **Security > Advisories > Report a vulnerability** özelliği etkinse onu kullanın. Etkin değilse güvenlik açığını herkese açık olarak ayrıntılandırmayın; repo sahibiyle özel bir iletişim kanalı açılmasını isteyin.

Katkılarda üçüncü taraf izleme, haricî API, kişisel veri toplama, başvuru ve ödeme sistemleri varsayılan olarak eklenmez. Bu işlevler için ayrıca hukuki/gizlilik, yetki, güvenlik ve operasyonel değerlendirme gerekir.

Şu anki yayın hedefi statik bilgilendirme prototipidir; bir sağlık hizmeti veya acil müdahale sistemi değildir.
