# Service blueprint
Need → discovery → information → verified referral → feedback.
Frontstage: website, search, articles, resource directory, feedback.
Backstage: needs research, UX, medical review, directory verification, quality.
Systems: CMS, search, directory, privacy-friendly analytics.
Care, Family, Kids & Youth, Support, Rights, Life, Work, Knowledge, Community, Academy, Volunteer, Global, Donate, Memorial are planned areas only. No health data collection, direct care, donations or community launch without approval.
