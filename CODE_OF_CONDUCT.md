# Katılımcı Davranış Kuralları

ZAINAB topluluğunda saygılı, kapsayıcı, yapıcı ve olgulara dayalı iletişim beklenir. Kanser deneyimi yaşayan kişiler, yakınları ve yas sürecindeki bireyler hakkında küçümseyici, suçlayıcı veya korku yayan bir dil kabul edilmez.

Tartışmalarda kişileri değil, fikirleri ve kanıtları değerlendirin. Taciz, ayrımcılık, tehdit, kişisel bilgi ifşası veya spam kabul edilmez.

Sorunları bir GitHub Issue veya proje bakımcısına uygun GitHub kanalı üzerinden bildirin; **hassas kişisel ya da güvenlik verisini açık Issue'ya yazmayın**. Bakımcılar uygunsuz içerikleri kaldırabilir ve katılımı sınırlandırabilir.

Tüm katkılar, proje ilkelerine ve mevcut GitHub platform kurallarına tabidir.
